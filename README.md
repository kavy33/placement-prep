# PrepDeck — Placement Prep Workspace

A responsive, dependency-free starter website for organizing software placement preparation. It uses plain HTML, CSS, and JavaScript, so it can be opened locally without installing plugins or packages.

## Run it

Open `index.html` in a browser. Daily task checkboxes are saved in that browser with `localStorage`.

## Included sections

- Overview dashboard with a sample weekly plan and study stats
- DSA patterns and an interview problem-solving checklist
- OS, DBMS, networking, and OOP revision prompts
- Project portfolio prompts and a project explanation framework
- DSA, core CS, behavioral, and project mock interview prompts
- Progress overview and locally saved daily task completion
- A 350-question interview bank: 50 each for DSA, OS, DBMS, networks, OOP/design, projects, and behavioral interviews; answers are concise speaking guides, not memorization scripts
- The question bank can be filtered by subject, answer length (short/long), and guided difficulty (easy/mid/hard)
- Separate shortcuts open the 50-question HR round set and a curated 50-question MNC focus collection

## Customize

Edit the sample topics and numbers in `index.html` to match your preparation. The dashboard metrics and topic completion values are starter content; they are not connected to a backend. Task completion is stored on the current browser/device only.
